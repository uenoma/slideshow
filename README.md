# slideshow

Mac と Windows のデスクトップ向けスライドショーアプリです。

## 機能

- 指定フォルダー内の画像を読み込む
- 画像をファイルの日付順に並べ替える
- 表示時間を設定して自動で次の画像に切り替える
- 再生 / 一時停止 / 前後移動を操作できる
- Flutter のデスクトップターゲットで動作する

## 実行方法

1. 依存関係を取得する
   - `flutter pub get`
2. 実行する
   - `flutter run -d macos`
   - `flutter run -d windows`

macOS では、選択したフォルダー内の画像の読み込みとコピーのために、ユーザーが選択したファイルへの読み書き権限を使用します。権限設定を変更した場合はアプリを再ビルドしてください。

## 使い方

- 「フォルダーを選択」を押して画像が入っているフォルダーを選ぶ
- 表示時間を秒単位で選ぶ
- 再生ボタンでスライドショー開始
- 画像は順番に自動で切り替わる

## 補足

Flutter のデスクトップ API では、すべてのプラットフォームで「ファイル作成日時」を完全に取得できるわけではありません。そこでアプリでは、表示順を安定させるためにファイルの更新日時を基準にしたソートを行っています。
